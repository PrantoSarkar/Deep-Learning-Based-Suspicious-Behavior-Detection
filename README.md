## 🔬 About the Research

This research investigates the use of automated human activity recognition for security and surveillance applications.

The study focuses on analyzing human behavior from video surveillance data using deep learning and machine learning techniques in order to identify potentially suspicious activities.

The goal is to support faster and more reliable threat identification by reducing dependence on continuous manual monitoring.

## 🎯 Research Objective

The main objective of this research is to develop an intelligent approach for analyzing human behavior and detecting suspicious activities that may be associated with criminal or threatening situations.

The study explores how machine learning and deep learning can improve surveillance systems by providing automated behavioral analysis.
